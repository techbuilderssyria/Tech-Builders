# بناة التقنية | Tech Builders

موقع تعريفي عربي متكامل باتجاه RTL وتصميم متجاوب للجوال والكمبيوتر. تم إنشاؤه باستخدام HTML وCSS وJavaScript فقط، لذلك لا يحتاج إلى تثبيت مكتبات أو تشغيل أوامر npm.

## تشغيل الموقع على جهازك

1. فك ضغط ملف المشروع إن كان مضغوطاً.
2. افتح مجلد `tech-builders-site`.
3. انقر مرتين على `index.html` لفتح الموقع في المتصفح.
4. للتعديل، افتح الملفات باستخدام Visual Studio Code أو أي محرر نصوص.

## أهم الملفات

- `index.html` — محتوى وأقسام الموقع.
- `styles.css` — التصميم والألوان والتجاوب مع الجوال.
- `script.js` — قائمة الجوال، الأسئلة الشائعة، نموذج التواصل، والمساعد التجريبي.
- `config.js` — بريد الشركة ورقم واتساب وروابط حسابات التواصل.
- `favicon.svg` — أيقونة الموقع.

## إعداد بيانات الشركة

افتح `config.js` وعدّل القيم التالية:

```js
window.TECH_BUILDERS_CONFIG = {
  email: "hello@yourcompany.com",
  whatsapp: "9639XXXXXXXX",
  phone: "",
  socials: {
    instagram: "https://instagram.com/your-account",
    facebook: "https://facebook.com/your-account",
    linkedin: "https://linkedin.com/company/your-company",
    tiktok: "https://tiktok.com/@your-account",
    x: "https://x.com/your-account",
    github: "https://github.com/your-account"
  }
};
```

استخدم بياناتكم الحقيقية فقط. رقم واتساب يجب أن يتضمن رمز الدولة وأرقاماً فقط، بدون علامة `+` أو مسافات. المنصات التي لا تضيف رابطها ستُخفى تلقائياً من الموقع.

## ملاحظة مهمة حول نموذج التواصل

الموقع واجهة ثابتة (Static Website)، ولا يحتوي حالياً على خادم خلفي لإرسال الطلبات أو حفظها في قاعدة بيانات. النموذج يتحقق من الحقول ويجهّز ملخصاً للطلب، ويفتح رسالة بريد جاهزة عندما تضيف عنوان بريد صحيحاً في `config.js`. هذا لا يعني أن الطلب أُرسل تلقائياً؛ يجب على الزائر إرسال الرسالة من تطبيق البريد. لاستقبال الطلبات مباشرة دون تدخل الزائر، اربط النموذج بخادم أو بخدمة استقبال نماذج موثوقة.

## ملاحظة حول المساعد التجريبي

دردشة الموقع عبارة عن نموذج تفاعلي بإجابات مكتوبة مسبقاً لشرح فكرة مساعد العملاء. ليست متصلة بواجهة ذكاء اصطناعي حقيقية ولا ترسل المحادثات إلى الشركة. لربط مساعد حقيقي، يلزم إعداد Backend آمن يتصل بمزوّد النموذج ويحمي مفاتيح API.

## النشر

يمكن رفع الملفات كما هي إلى استضافة المواقع الثابتة مثل GitHub Pages أو Netlify أو أي استضافة تدعم HTML/CSS/JS. لا ترفع مفاتيح API أو كلمات مرور داخل `config.js`.

## تخصيص الهوية
